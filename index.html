For grown-ups

Overview and how to use this page

This activity teaches 100 common words in 10 sets of 10. The words and their grouping are the list you supplied; I have not verified them against any published word list. The practice sentences and spelling notes were written for this activity.

  • Learn walks through each word: say it, look closely, spell it, hide it, try it, check it, use it in a sentence.
  • Practice: type it hides the word. The child hears it (or you say it), then types it. A wrong try is kept on screen next to the correct spelling, with the letters to notice highlighted. The child studies it, then tries again from memory.
  • Practice: paper with a grown-up is for writing with a pencil. You see the word, say it, and mark the result.
  • Words spelled correctly on the first try with no help count as “on my own.” Words spelled after seeing the word count separately as “after seeing the word.” One correct answer does not make a word “mastered.”
  • No timers, scores against others, or penalties. Short sessions of about 5–10 minutes work well.

Hearing words: the “Hear the word” button uses the device’s built-in voice if there is one. Voices and pronunciation vary by device. If it is not available, the page asks a grown-up to say the word. Nothing plays automatically.

Keyboard clues: autocorrect, spell-check, and capital letters are turned off for the answer box where the browser allows it, but an iPad keyboard may still show word suggestions. If that is a problem, use the paper mode.

Privacy: nothing is sent anywhere. Progress stays on this device, in this browser, unless you save the progress file and share it yourself. Browser storage can be cleared by the browser, so use “Save progress” if you want a backup. No names or personal details are collected.

Opening this file: an iPad file preview may show this page without running JavaScript. In that case you can read the words and steps but cannot practice. Open it in Safari for the interactive version. This is a downloaded file, not a website address.
